---
title: There’s no single best way to deploy an LLM tutor.
factors:
  - title: How well it teaches
    body: >-
      A correct answer isn’t always a helpful one. Explanations and guidance
      have to help a student learn, not just be accurate.
  - title: What it costs to run
    body: >-
      Every question spends API tokens or compute. The model, the amount of
      course context and the length of the conversation all move the bill.
  - title: How fast and reliably it answers
    body: >-
      The model, its provider and the interface in front of it all change how
      quickly and how dependably answers arrive.
  - title: Where learners work
    body: >-
      A terminal next to the assignment, a course Discord server, a department
      Slack workspace. The tutor has to meet students where they already ask.
closing: >-
  So we’re building a reproducible benchmark and a set of recommendations, so
  instructors and developers can choose a model or tutor with evidence instead
  of impressions.
---

The right choice depends on how well a model teaches, what it costs, how
quickly and reliably it responds, and where learners work.
